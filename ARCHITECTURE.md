# SABT — Architecture Specification

Version: 0.1
Status: Draft / Architecture Baseline

SABT is a local/LAN Persian-first document and operation management system. It is not an accounting, payment-processing, CRM, advertising, or official registry system.

## Core principles
- Operation is the central business process entity.
- Appointment and Operation are independent.
- An Operation may have zero or one Contract.
- Contract Number is manually entered and is not a database primary key.
- Registration Number is generated by configurable Admin policy.
- Person and Property are reusable master entities; finalized operations preserve immutable snapshots.
- Documents are first-class entities: file bytes on filesystem, metadata in SQLite.
- Finalized records are corrected through versioned correction workflows and audit, not ordinary in-place editing.
- Backend dates/timestamps are Gregorian; Persian UI/forms/reports use Jalali.
- Print layout uses mm in the UI and PDF points internally.
- Clients communicate with FastAPI; clients never open SQLite directly.

## Deployment
Clients -> HTTP -> FastAPI -> SQLAlchemy -> SQLite
                                  -> filesystem storage
                                  -> generated PDFs
                                  -> templates/branding
                                  -> backups

V1 targets Windows/local LAN. The persistence layer must remain suitable for future PostgreSQL migration.

## Major modules
Dashboard, Appointments, Operations, Contracts, People, Properties, Documents, Form Designer/PDF, QR, Restrictions, Reminders, Projects, Operation Types, Users/Roles/Permissions, Audit, Backup/Restore, Settings.

## Non-goals
No payment gateway, accounting ledger, bank integration, public marketplace, or replacement of the official registry.

## Technology direction
Backend: Python, FastAPI, SQLAlchemy, Alembic, SQLite.
Frontend: lightweight server-rendered HTML/templates, CSS, JavaScript, RTL-first Persian UI.
Printing: template-driven PDF generation with mm-based designer coordinates.
