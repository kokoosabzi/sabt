# راه‌اندازی مدیر اولیه SABT

این دستور فقط برای پایگاه داده‌ای است که مهاجرت‌های Alembic روی آن اجرا شده و هنوز هیچ حساب کاربری ندارد.

## اجرای محلی در Windows PowerShell

از پوشه اصلی مخزن:

```powershell
$env:SABT_DATA_DIR = "$env:LOCALAPPDATA\SABT\data"
python -m pip install -e .
python -m alembic upgrade head
python -m app.bootstrap
```

برنامه نام کاربری، نام نمایشی و گذرواژه را به‌صورت تعاملی دریافت می‌کند. گذرواژه در آرگومان خط فرمان قرار نمی‌گیرد و در خروجی چاپ نمی‌شود. حداقل طول گذرواژه ۱۲ نویسه است.

پس از موفقیت، سرور را اجرا کنید:

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

سپس پرتال محلی را باز کنید:

```
http://127.0.0.1:8000/portal/
```

## ساخت اولین پروژه پس از ورود

اگر مدیر اولیه هنوز هیچ پروژه‌ای در دسترس نداشته باشد، پرتال به‌جای صفحه گزارش‌ها فرم «ساخت اولین پروژه» را نمایش می‌دهد. این فرم اطلاعات زیر را دریافت می‌کند:

- نام پروژه
- شناسه داخلی یکتای پروژه
- کد دو رقمی قرارداد از ۱۰ تا ۹۹
- منطقه زمانی پروژه (پیش‌فرض `Asia/Tehran`)
- توضیحات اختیاری

پس از ثبت، سرور پروژه را ایجاد می‌کند و دسترسی فعال مدیر ایجادکننده را در همان تراکنش ثبت می‌کند. پرتال سپس شناسه پروژه را به‌طور خودکار انتخاب و داشبورد را بارگذاری می‌کند.

APIهای فعلی این مرحله:
- `POST /projects` — ایجاد پروژه (نیازمند ورود و مجوز سراسری `project.create`)
- `GET /projects` — فهرست پروژه‌هایی که کاربر عضویت فعال و مجوز مشاهده آن‌ها را دارد

کد دو رقمی پروژه در شماره‌گذاری قرارداد مادر استفاده می‌شود؛ این کد برای پروژه‌های جدید اجباری است و باید یکتا باشد.

## محدودیت‌های ایمنی

- این ابزار فقط وقتی مجاز است که جدول کاربران خالی باشد.
- اگر حتی یک کاربر وجود داشته باشد، ابزار متوقف می‌شود و هیچ حسابی را بازنویسی نمی‌کند.
- نقش مدیر اولیه با کاتالوگ مجوزهای مرکزی برنامه ساخته می‌شود؛ مجوزها در دیتابیس ذخیره می‌شوند.
- مدیر اولیه یک نقش سراسری دارد. دسترسی به عملیات پروژه‌ای همچنان به عضویت فعال در همان پروژه نیاز دارد.
- این ابزار مدیر یا رمز پیش‌فرض تولید نمی‌کند.
- اگر قبلاً حساب ساخته شده و رمز آن فراموش شده باشد، این ابزار راه بازیابی رمز نیست؛ فرایند بازیابی/بازنشانی حساب موجود باید جداگانه طراحی و ممیزی شود.

> این راهنما برای مرحله توسعه است. بسته نصب نهایی Windows، راه‌اندازهای setup/start/stop و فرایند بازیابی رمز هنوز در دست توسعه‌اند.
