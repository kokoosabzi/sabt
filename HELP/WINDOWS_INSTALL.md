# نصب و اجرای محلی SABT روی Windows

## پیش‌نیاز

- Windows 10 یا Windows 11
- Python 3.12 و Python Launcher (`py.exe`)
- اتصال اینترنت برای دریافت اولیه بسته‌های Python

## نصب اولیه

1. مخزن SABT را در یک مسیر قابل‌نوشتن استخراج یا clone کنید.
2. فایل `setup.bat` را اجرا کنید.
3. اسکریپت محیط مجازی `.venv` را می‌سازد، وابستگی‌ها را نصب می‌کند و مهاجرت‌های دیتابیس را اجرا می‌کند.
4. در نصب تازه، اطلاعات مدیر اولیه را تعاملی دریافت می‌کند. گذرواژه پیش‌فرض وجود ندارد و در خط فرمان ذخیره نمی‌شود.

داده‌های نصب پیش‌فرض در مسیر زیر قرار می‌گیرند:

```
%LOCALAPPDATA%\SABT\data\sabt.db
```

گزارش‌های اجرای سرور در `%LOCALAPPDATA%\SABT\logs` و PID در `%LOCALAPPDATA%\SABT\run` نگهداری می‌شود.

## اجرای روزمره

- اجرای `start.bat`: مهاجرت‌های جدید را اعمال می‌کند، سرور را در پس‌زمینه بالا می‌آورد، سلامت آن را بررسی می‌کند و پرتال را باز می‌کند.
- نشانی پرتال: `http://127.0.0.1:8000/portal/`
- اجرای `stop.bat`: فقط پردازشی را متوقف می‌کند که PID آن ثبت شده و فرمان اجرای آن با سرور SABT مطابقت داشته باشد.

سرور فعلاً فقط روی `127.0.0.1` گوش می‌دهد؛ بنابراین از شبکه محلی یا اینترنت قابل دسترسی نیست. انتشار روی LAN نیازمند تصمیم امنیتی و پیکربندی جداگانه است.

## پشتیبان‌گیری و بازیابی SQLite

در نسخه فعلی، ابزار خط فرمان برای پشتیبان‌گیری آنلاین و بازیابی آفلاین اضافه شده است.

ساخت نسخه پشتیبان در حالی که سرور روشن است:

```powershell
.\.venv\Scripts\python.exe -m app.backup create
```

بازیابی فقط پس از توقف سرور:

```powershell
.\stop.bat
.\.venv\Scripts\python.exe -m app.backup restore "C:\path\to\sabt-backup.db" --confirm
.\start.bat
```

- پشتیبان‌گیری از SQLite Online Backup API استفاده می‌کند تا داده‌های commit‌شده در WAL نیز در نسخه پشتیبان باشند.
- مسیر پیش‌فرض پشتیبان‌ها `%LOCALAPPDATA%\SABT\backups` است؛ متغیر `SABT_BACKUP_DIR` می‌تواند آن را تغییر دهد.
- بازیابی در صورت وجود فایل PID سرور متوقف می‌شود و نیازمند گزینه صریح `--confirm` است.
- پیش از جایگزینی دیتابیس فعلی، یک نسخه ایمنی با پیشوند `sabt-pre-restore-` ساخته می‌شود.
- پس از بازیابی، `start.bat` مهاجرت‌های جدید Alembic را اعمال می‌کند.

فایل پشتیبان حاوی اطلاعات واقعی کاربران و قراردادهاست؛ آن را مانند دیتابیس اصلی محافظت کنید. رمزنگاری فایل پشتیبان و سیاست نگهداری/حذف دوره‌ای هنوز در این مرحله پیاده‌سازی نشده‌اند.

## دیتابیس‌های توسعه قبلی

نسخه توسعه از مسیر نسبی `./sabt.db` استفاده می‌کرد. راه‌انداز Windows دیتابیس را خودکار جابه‌جا یا کپی نمی‌کند. اگر فایل `sabt.db` در ریشه مخزن وجود داشته باشد و مسیر داده جدید انتخاب شده باشد، `setup.bat` متوقف می‌شود تا داده قدیمی به‌اشتباه نادیده گرفته نشود.

برای استفاده از همان دیتابیس موجود، پیش از اجرای setup مقدار `SABT_DATA_DIR` را به پوشه‌ای تنظیم کنید که فایل `sabt.db` در آن قرار دارد؛ سپس setup و start را از همان نشست اجرا کنید. قبل از هر جابه‌جایی دستی، از فایل دیتابیس و فایل‌های WAL آن نسخه پشتیبان تهیه کنید و مطمئن شوید برنامه متوقف است.

## مواردی که هنوز در این مرحله تحویل نشده‌اند

- ابزار رسمی Backup و Restore از داخل برنامه
- نصب‌کننده مستقل `.exe` یا MSI
- اجرای سرویس Windows در زمان ورود کاربر/راه‌اندازی سیستم
- دسترسی شبکه محلی چندکاربره
- بازیابی یا بازنشانی امن گذرواژه حساب موجود

آزمون Windows CI راه‌اندازی، اجرای سرور، پاسخ Health/Portal و توقف پردازش را بررسی می‌کند؛ این آزمون جایگزین بررسی روی رایانه نهایی کاربر نیست.
